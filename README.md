# CCC Delivery
![C#](https://img.shields.io/badge/C%23-blueviolet?style=flat-square)
![Unity](https://img.shields.io/badge/unity-%23000000.svg?style=flat-square&logo=unity&logoColor=white)
![image](https://github.com/ares-ro/CCCDelivery/blob/main/docs/readme%20image.png)
넥슨의 블루아카이브 게임 설정을 기반으로 만든 비공식 미니게임입니다.
달려드는 적들을 처치하며 제한시간동안 버티는 게임입니다.

# 실행방법
1. 다운로드 후 압축 해제합니다.
2. CCCDelivery.exe를 실행합니다.

# 상세
### 게임 설명
![image](https://github.com/ares-ro/CCCDelivery/blob/main/docs/readme%20image2.png)

| 번호 | 설명 |
| :--- | :--- |
| 1 | 열차의 체력입니다. 적의 공격을 통해 줄어들며 0%가 될 경우 종료 화면으로 이동됩니다. |
| 2 | 제한시간입니다. 10분의 시간이 주어집니다. 해당 시간동안 최대한 적을 처치하며 열차가 파괴되지 않도록 버티면 됩니다. |
| 3 | 맵에 등장하는 적입니다. 총 6종류의 적이 등장하며 제한시간이 임박할수록 더 강한 적이 등장합니다. |
| 4 | 플레이어가 사용할 수 있는 공격 스킬입니다. 표시된 A, S, D, F 키를 이용해 사용할 수 있으며 적을 처치해 얻은 크레딧으로 강화할 수 있습니다. |
| 5 | 열차입니다. 적은 이 부분을 향해 공격하게 됩니다. 플레이어가 공격하는 스킬도 해당 부분에서 시작합니다. |
